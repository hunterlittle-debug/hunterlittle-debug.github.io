Overview

The project

I wanted LED lighting in my home that I could control with my voice or my phone, and I wanted to build it myself.

Right now it runs one room with 8 strips of WS2812B LEDs. The strips plug into an 8-port ESP32 board running WLED. A Raspberry Pi 5 runs Homebridge, which controls the WLED board and connects everything to Apple Home, so it works with HomePod and my iPhone.

I soldered and mounted all the electronics myself. Everything is inside a cabinet and the wires run through the drywall, so you can't see any of it. It's easy to add more rooms later.

What it had to do

  • Control the lights from one system, starting with one room
  • Work with HomePod and my iPhone
  • Run on my Raspberry Pi 5 with Homebridge
  • Hide all the electronics and wires
  • Be easy to add more rooms to

Decisions

Design choices

The main calls I made and why.

01

Building it myself with a Pi and Homebridge

I set up a Raspberry Pi 5 running Homebridge to control everything.

Why: Homebridge lets the lights show up in Apple Home. And because I built it myself, I know how it all works, so I can copy it to more rooms and fix it if something breaks.

02

Hiding the electronics

I soldered all the modules and controllers and mounted them inside a cabinet.

Why: I didn't want any electronics or wires showing, so the boards went in the cabinet and the wiring went through the drywall.

03

Running on a schedule

I set up a HomeKit automation that turns the lights on and off depending on the time.

Why: So the lights turn on and off by themselves.

Reflection

What I learned

Building it myself meant I had to figure out every part, from the software to the wiring to the install. Now that I understand how it works, adding a room or fixing something isn't a big deal.
