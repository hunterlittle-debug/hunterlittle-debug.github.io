Overview

The problem

I wanted to control every light in the house from one place, by voice or phone, without paying for a closed commercial hub.

I designed and installed a whole-home lighting automation system run by a Raspberry Pi 5 on Homebridge, which lets the lights work with Apple HomePod and iOS devices. I soldered and mounted all the electronic modules and controllers myself.

It currently runs one room with 8 LED light strips, driven by an 8-port ESP32-based LED distribution board running WLED. A Raspberry Pi 5 runs Homebridge to control the WLED board, which brings the lights into Apple Home. It's built so more rooms can be added easily. All of the electronics are mounted inside a cabinet, with the wiring run through the drywall so nothing is visible.

Goals & requirements

  • Control lighting across the whole home from one system
  • Work with Apple HomePod (voice) and iOS devices
  • Run on a Raspberry Pi 5 using Homebridge
  • Hide all electronics and wiring for a clean install
  • Easy to expand to more rooms later

Engineering decisions

Design choices

The key decisions I made, the alternatives I weighed, and why I picked what I did.

01

Raspberry Pi 5 + Homebridge as the hub

Used a Raspberry Pi 5 running Homebridge instead of a commercial smart-home hub.

Why: Homebridge bridges non-HomeKit devices into Apple Home, so the system works with HomePod and iOS. Building it myself meant I understood exactly how it worked, so I could copy it to more rooms and fix it if anything breaks.

02

Soldered, mounted modules

Soldered and mounted all electronic modules and controllers.

Why: Soldered joints are more reliable than breadboards or loose connectors for a permanent install. I mounted everything inside a cabinet to hide the electronics and ran the wiring through the drywall.

03

Automation with HomeKit

Set up a HomeKit automation that turns the lights on and off based on the time of day.

Why: Using Apple's built-in automations meant no extra software to maintain, and the schedule can be changed from a phone in seconds.

Reflection

What I learned

Building the system myself instead of buying a finished product meant I had to understand every part of it: the software, the wiring, and the install. That understanding is what makes it easy to expand and repair now.
